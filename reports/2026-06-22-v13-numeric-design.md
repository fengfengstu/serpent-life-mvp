# 《此生为蛇》V13 数值逻辑重构策划案

判断：V13 的重构重点只有一个，把“身体长度”做成可见、可消耗、可受伤、可构筑、可操作的核心资源。躲怪、吃经验、抽技能都是外层动作；真正的乐趣来自玩家用蛇身在“变长、献祭、受伤、围猎、修复”之间不断换算。

实现口径：本方案按 Phaser/HTML5 移动端 Demo 约束设计。Phaser 的输入系统把鼠标与触控统一为 pointer 事件，适合单指拖动蛇首；Scene 可拆分主游戏、UI、暂停选卡、Boss 等逻辑层；Timer 可用于波次、保底、事件、Boss 阶段调度；Scale Manager 可适配移动端画布比例。蛇身碰撞建议使用采样点、圆形 overlap、同源冷却，不依赖复杂刚体分离，因为 Arcade Physics 在大量物体贴近时稳定性有限。([docs.phaser.io][1])

---

## 1. 一句话核心判断

《此生为蛇》的核心乐趣应定义为：

> 玩家用越来越长的蛇身获得更大的生存空间、攻击面积、拾取范围和动作构筑机会，再把一部分身体献祭成技能，形成“成长—献祭—变强—承压—修复—再成长”的局内循环。

V13 要删掉三个错误方向：

| 错误方向         |              后果 | V13 修正                        |
| ------------ | --------------: | ----------------------------- |
| 身体只是 HP 数字   | 玩家只关心血量，不关心蛇身形态 | 身体必须影响拾取、攻击节点、技术动作、受击面积、技能消耗  |
| 技能升级只像传统经验升级 |       技能卡与蛇主题脱节 | 技能学习消耗身体，消耗前后都要有可见动画和战术影响     |
| 长身体只带来碰撞风险   |         玩家会害怕成长 | 长身体提供更高收益，风险通过裂痕缓冲，不直接惩罚速度和操作 |

V13 的核心设计准则：

`长身体 = 更大收益 + 更大暴露面 + 更高可献祭额度`

`短身体 = 更安全的轮廓 + 更少攻击节点 + 更低构筑上限`

## 2. 核心循环重定义

### 30 秒循环：看懂核心

玩家在做什么：

* 单指拖动蛇首，吃记忆碎片。
* 身体从 12 节增长到 16–18 节。
* 第一次看见身体节点增加、尾巴延长、拾取范围变大。
* 怪物从远处进入，玩家通过移动路线让蛇身参与攻击或阻挡。
* 技能选择进度接近满格，准备生成第一枚技能核。

获得反馈：

* 身体增长是视觉反馈，不是 UI 数字。
* 头部受击会明显断尾，身体受击先出现裂痕。
* 长身体带来更宽的记忆吸附范围和更多身体攻击触发点。

再玩理由：

* 30 秒内能理解“身体是命，也是资源”。
* 第一枚技能核即将出现，形成继续玩的短期动机。

### 3 分钟循环：形成构筑

玩家在做什么：

* 完成第一关，击杀第一个 Boss 或小 Boss。
* 拥有 3–4 次技能选择。
* 身体经历过增长、献祭、裂痕、修复。
* 至少触发过一次小三角或小圈动作。
* 玩家开始知道自己这一局偏向毒牙、鳞雨、盘绕、护盾、经济或机动。

获得反馈：

* 技能升级消耗身体后，蛇明显变短，但攻击方式改变。
* Boss 有血条、阶段、弱点，技能能稳定命中。
* 精英和事件提供一次“意料之外”的奖励。

再玩理由：

* 同样的蛇身长度，不同技能组合会改变移动路线。
* Boss 奖励能改变后两关的构筑方向。

### 8 分钟循环：完成 Demo 局内叙事

玩家在做什么：

* 完成第一关、第二关、第三关。
* 拥有 7–8 次技能选择，技能总等级约 8–11。
* 经历 2–3 个随机事件、3 个 Boss 奖励、若干精英词缀。
* 长身体、短身体、过载身体三种状态都能感受到。

获得反馈：

* 最终 Boss 明确吃技能伤害，弱点阶段鼓励技术动作。
* 身体长度在 32–45 节之间波动，玩家能看出自己构筑的代价。
* 稀有卡、Boss 词缀、过载记忆提供局内惊喜。

再玩理由：

* 下一局可以换一个主技能、不同献祭节奏、不同 Boss 奖励路线。
* Demo 不需要复杂局外成长，也能有肉鸽式差异。

## 3. 资源系统设计

### 3.1 资源定义

| 资源      |    缩写 | 类型      | 来源                     | 消耗/损失               | 主要作用                     | 设计边界               |
| ------- | ----: | ------- | ---------------------- | ------------------- | ------------------------ | ------------------ |
| 身体长度    |   `L` | 核心资源    | 记忆经验成长、Boss 奖励、事件      | 受击、学习技能、过载偿还失败      | 生命、技能成本、攻击节点、拾取范围、技术动作尺度 | 不能隐藏成纯数字           |
| 身体裂痕    |   `C` | 伤害缓冲    | 身体受击、弹幕擦碰、过载副作用        | 修复记忆、蜕皮护盾、技术动作、小关结算 | 表达身体受损，但避免身体一碰就断         | 不能替代身体长度成为主血条      |
| 记忆经验    | `MXP` | 成长经验    | 地面记忆、击杀掉落、事件           | 身体成长、偿还过载           | 增长身体                     | 不直接升级技能            |
| 技能经验    | `SXP` | 选卡进度    | 击杀、技能碎片、精英、技术动作        | 填满后生成技能核            | 决定技能选择机会                 | 不直接增长身体            |
| 技能核     |   `K` | 选卡触发物   | `SXP` 满格、精英、Boss、事件    | 拾取后打开 3 选 1         | 控制技能卡节奏                  | 不自动弹窗打断移动          |
| 过载记忆    |   `O` | 债务/惊喜资源 | 身体不足时学习高阶技能、事件、Boss 奖励 | 后续记忆优先偿还            | 允许提前获得强技能，附带风险           | 最大 8 点，不能无限滚雪球     |
| Boss 奖励 |  `BR` | 大节点奖励   | Boss 死亡                | 选择 1 个奖励            | 改变构筑方向                   | 不消耗身体，避免 Boss 后负反馈 |

### 3.2 资源转换关系

```text
吃记忆 → MXP → 增加身体 L
击杀 / 技能碎片 / 技术动作 → SXP → 技能核 K → 技能卡 → 消耗 L 或增加 O → 技能等级
身体受击 → 裂痕 C → 达到阈值后断尾 → L 下降
修复记忆 / 蜕皮 / 小圈动作 → 清除 C
Boss 死亡 → BR → 稀有技能核 / Boss 词缀 / 身体修复 / 上限提高
过载 O → 后续 MXP 优先偿还 → 偿还后继续成长
```

### 3.3 避免资源混乱的硬规则

| 硬规则                 | 说明                  |
| ------------------- | ------------------- |
| `MXP` 只处理身体成长和过载偿还  | 玩家知道“吃记忆就是长身体”      |
| `SXP` 只处理技能选择机会     | 玩家知道“杀怪和技能碎片带来选卡”   |
| 技能学习只消耗身体，不消耗 `MXP` | 技能成本必须可视化为断尾/脱节     |
| Boss 奖励不消耗身体        | Boss 死亡必须是正反馈       |
| 裂痕先缓冲，断尾后才减少身体      | 身体受击不会让玩家瞬间崩盘       |
| 过载只允许短期借贷           | 高级技能可以提前拿，但后续成长会被占用 |

### 4.2 头部受击规则

| 来源          |  扣身体 | 附加裂痕 | 说明            |
| ----------- | ---: | ---: | ------------- |
| 普通近战怪碰头     | -3 节 |    0 | 头部是最高风险部位     |
| 骨鸦冲刺碰头      | -2 节 |    0 | 高速怪伤害略低，避免冤死  |
| 精英近战碰头      | -4 节 |   +1 | 精英威胁明显        |
| 普通弹幕碰头      | -2 节 |    0 | 弹幕可躲，伤害低于近战   |
| Boss 普通攻击碰头 | -5 节 |   +1 | Boss 强惩罚      |
| Boss 大招碰头   | -6 节 |   +2 | 必须有 1.0 秒以上预警 |

头部受击结算顺序：

```text
if invincible: ignore
else:
  L -= headDamageSegments
  C += extraCracks
  triggerInvincible(1.2s)
  clearNearbyProjectiles(radius=80px)
  if L < 4: death or once-per-run 残蜕保护
```

V13 建议加一次“残蜕保护”：

| 条件                           | 效果                                 | 限制                  |
| ---------------------------- | ---------------------------------- | ------------------- |
| 首次将 `L` 扣到 3 以下，且游戏时间 > 20 秒 | `L` 设置为 4，清空 120 px 内弹幕，获得 1.5 秒无敌 | 每局 1 次，Boss 第三阶段可禁用 |

面试 Demo 建议保留一次残蜕保护。它能减少首玩误判死亡，但不会改变最终 Boss 的压力。

### 4.3 身体受击与裂痕规则

身体受击不直接扣身体，先增加裂痕。

```text
C_max(L) = max(4, ceil(L / 6) + 2)

当 C >= C_max(L):
  tailLoss = min(4, 2 + floor(L / 24))
  L -= tailLoss
  C = max(0, C - ceil(C_max(L) * 0.6))
  触发断尾动画与 0.6 秒身体裂痕免疫
```

示例：

| 当前身体 `L` | 裂痕阈值 `C_max` | 达阈值断尾 | 设计目的          |
| -------: | -----------: | ----: | ------------- |
|       12 |            4 |    -2 | 新手能承受 3 次身体擦碰 |
|       18 |            5 |    -2 | 早期容错适中        |
|       30 |            7 |    -3 | 长身体承受更多裂痕     |
|       42 |            9 |    -3 | 中期长身体不脆       |
|       56 |           12 |    -4 | 后期身体大，裂痕容量也大  |

裂痕显示规则：

* 被击中的身体节点出现白裂纹。
* 裂痕数量超过 50% 阈值时，尾端轻微颤动。
* 达到阈值前 1 点时，身体边缘出现红色脉冲。
* 断尾时从尾端脱落，不从中间切断，避免路径和碰撞逻辑复杂化。

### 4.4 长身体收益与风险

| 身体长度区间 | 收益                 | 风险        | V13 处理         |
| -----: | ------------------ | --------- | -------------- |
|  12–18 | 拾取范围略增，基础攻击节点少     | 风险低       | 教学和第一技能前的安全区   |
|  19–30 | 技能发射节点增加，技术动作更容易成形 | 身体被擦碰概率上升 | 裂痕阈值同步提高       |
|  31–42 | 大圆、盘绕、身体系技能收益明显    | 怪物密度开始压迫  | 给修复、护盾、控制技能    |
|  43–56 | 高级构筑完整，Boss 围猎能力强  | 弹幕期裂痕堆积快  | Boss 弹幕按同源冷却处理 |
|  57–64 | Demo 展示上限          | 屏幕占用高     | 成长成本大幅提高，不鼓励常驻 |

不建议在 P0 给长身体加明显减速。长身体的风险来自暴露面和路径管理，移动速度惩罚会让成长变成负反馈。

## 5. 经验与成长公式

### 5.1 身体成长公式

`L` 为当前身体节数，成长到下一节需要：

```text
x = max(0, L - 12)

baseBodyCost(L) = ceil(4 + 0.45x + 0.012x²)

softCap = [教学 22, 第一关 30, 第二关 42, 第三关 56]

if L <= softCap:
  softMultiplier = 1.0
elif L <= softCap + 8:
  softMultiplier = 1.6
else:
  softMultiplier = 2.4

nextBodyCost = ceil(baseBodyCost(L) * softMultiplier)
```

身体成长结算：

```text
当 MXP >= nextBodyCost:
  MXP -= nextBodyCost
  L += 1
  每新增 2 节身体，清除 1 点最旧裂痕
```

* 身体 P90 不能长期超过 56，否则硬上限太容易触达。

## 6. 技能卡与技能核获取规则

### 6.1 技能选择进度

技能选择进度来自 `SXP`。第 `n` 次技能选择需要：

```text
skillChoiceCost(n) = floor(24 + 8n + 2 * n^1.35)
n 从 1 开始
```

成本表：

| 第几次技能选择 | 所需 `SXP` | 目标出现时间    |
| ------: | -------: | --------- |
|       1 |       34 | 35–45 秒   |
|       2 |       45 | 75–95 秒   |
|       3 |       56 | 120–150 秒 |
|       4 |       68 | 175–215 秒 |
|       5 |       81 | 235–285 秒 |
|       6 |       94 | 300–365 秒 |
|       7 |      107 | 375–450 秒 |
|       8 |      121 | 455–540 秒 |
|       9 |      134 | 560–660 秒 |
|      10 |      148 | 690–780 秒 |

Demo 8 分钟内，推荐中位数为 7–8 次技能选择。第 9–10 次用于高水平玩家或调试，不作为普通通关标准。

### 6.2 `SXP` 来源

| 来源        |                `SXP` |
| --------- | -------------------: |
| 普通近战怪击杀   |                   +1 |
| 骨鸦击杀      |                   +1 |
| 骸骨弩手击杀    |                 +1.5 |
| 铁壳守卫击杀    |                   +2 |
| 精英击杀      |                  +12 |
| 技能碎片拾取    |                   +6 |
| 小三角动作成功   |                   +2 |
| 小圈动作成功    |                   +4 |
| 大圆闭环成功    |                   +6 |
| Boss 阶段击破 |                  +10 |
| Boss 死亡   | 不加 `SXP`，直接给 Boss 奖励 |

### 6.3 技能核生成

当 `SXP` 满足当前技能选择成本：

```text
if timeSinceLastCard >= 28s:
  spawnSkillCore()
else:
  pendingCore += 1
  pendingCoreMax = 2
```

技能核生成位置：

```text
距离蛇首 160–240 px
与最近敌人距离 > 180 px
与 Boss 大招预警区不重叠
优先生成在玩家移动方向前方 ±70°
如果 2 秒内找不到安全点，延迟 0.5 秒重试
```

技能核不会自动弹卡。玩家拾取技能核后，才打开技能卡选择界面。这样可以避免移动中被强制打断。

### 6.4 第一次技能选择

教学关：

```text
T = 32s 强制生成第一枚教学技能核
只出现 3 张固定安全卡：
毒牙投射 Lv1
蜕皮护盾 Lv1
吞忆磁场 Lv1
```

正式第一关：

```text
if T >= 35s and (L >= 15 or 已拾取记忆数 >= 10):
  生成第一枚技能核
if T >= 45s and 尚未生成:
  强制生成第一枚技能核
```

第一关第一枚技能核不能生成高级成本卡，所有可选卡消耗身体不超过 3 节。

### 6.5 防止频繁弹卡

| 机制        |        数值 |
| --------- | --------: |
| 两次选卡最小间隔  |      28 秒 |
| 待领取技能核上限  |       2 个 |
| 技能核存在时间   |       不消失 |
| 同屏技能核上限   |       1 个 |
| 选卡界面暂停游戏  |         是 |
| 选卡后保护     |     0.8 秒 |
| 单次选卡目标时长  |     3–8 秒 |
| 每分钟选卡次数上限 | 实际不超过 2 次 |

Phaser 可以用独立 UI Scene 叠在主游戏 Scene 上实现选卡暂停与恢复，减少主循环状态污染。([docs.phaser.io][2])

### 6.6 身体不足时抽到高级技能

技能卡有身体消耗：

```text
availableBody = L - L_reserve

if cardCost <= availableBody:
  L -= cardCost
  学习成功
else:
  paid = max(0, availableBody)
  deficit = cardCost - paid
  L -= paid
  O += deficit
  学习成功，进入过载状态
```

过载规则：

| 过载记忆 `O` | 效果                                        |
| -------: | ----------------------------------------- |
|      1–3 | 后续 `MXP` 优先偿还，5 `MXP` 抵消 1 点 `O`          |
|      4–6 | 技能伤害 +3% × `O`，但身体受击时额外 +1 裂痕             |
|      7–8 | 技能伤害 +3% × `O`，身体受击额外 +1 裂痕，成长经验转化效率 -20% |
|       >8 | 不允许继续过载，卡牌显示为“身体不足，需先成长”                  |

这条规则保留高级卡的惊喜，不让玩家因为身体不足完全失去选择。

## 7. 技能升级经济

### 7.1 全局规则

* 每张技能卡提升一个技能等级，最高 Lv5。
* 新学技能从 Lv1 开始。
* 学习和升级都消耗身体。

## 8. 技术动作系统

技术动作是玩家通过蛇身操作形成的路线奖励，不占技能卡输入。移动端只需要单指拖动。

检测方式：

```text
每 80ms 记录蛇首位置
保留最近 6 秒轨迹
计算：
  pathLength
  startEndDistance
  signedAngleSum
  boundingBoxArea
  sharpTurnCount
  enclosedEnemies
  nearestBodyDistance
```

### 8.1 小三角：折返成势

| 项目      | 规则                                                    |
| ------- | ----------------------------------------------------- |
| 难度      | 低                                                     |
| 触发条件    | 2.5 秒内出现 3 次明显转向；每次转向角度 > 45°；轨迹包围面积 2,500–12,000 px² |
| 容错      | 起终点不需要闭合；允许 1 次转向角不足但整体角度达标                           |
| 奖励      | 对三角区域内敌人造成 20 伤害；`SXP +2`；触发荆棘盘绕 Lv1 效果               |
| 冷却      | 6 秒                                                   |
| 风险      | 折返时容易让身体暴露给追击怪                                        |
| 移动端可操作性 | 玩家只需画一个小折线，不要求精确图形                                    |
| 教学方式    | 教学关显示 3 个淡色引导点，玩家沿点拖动一次即可成功                           |

### 8.2 小圈：回身噬忆

| 项目      | 规则                                            |
| ------- | --------------------------------------------- |
| 难度      | 中                                             |
| 触发条件    | 3 秒内累计转向角 > 300°；起终点距离 < 70 px；轨迹半径 45–110 px |
| 容错      | 圆可以变形；闭合误差允许 70 px；不要求围住敌人                    |
| 奖励      | 吸附 160 px 内记忆；修复 1 裂痕；释放 60 px 环形伤害 18        |
| 冷却      | 10 秒                                          |
| 风险      | 圈太小会让头部贴近身体路径，容易被追击怪压住                        |
| 移动端可操作性 | 拇指小范围画圈即可                                     |
| 教学方式    | 第一关第 60 秒出现一次“记忆涡”，引导玩家画圈吸收                   |

### 8.3 大圆闭环：盘身围猎

| 项目      | 规则                                                              |
| ------- | --------------------------------------------------------------- |
| 难度      | 中高                                                              |
| 触发条件    | 4.5 秒内累计转向角 > 330°；轨迹包围面积 > 38,000 px²；`L >= 18`；起终点距离 < 120 px |
| 容错      | 允许椭圆；允许闭合点偏离；只要包围面积和转向达标                                        |
| 奖励      | 圆内普通敌人减速 40% 持续 3 秒；Boss 弱点暴露或易伤 +10% 持续 5 秒；`SXP +6`           |
| 冷却      | 18 秒                                                            |
| 风险      | 动作时间长，容易被弹幕和远程怪干扰                                               |
| 移动端可操作性 | 适合 Boss 阶段，不要求频繁使用                                              |
| 教学方式    | 第二关 Boss 前用半透明大圆提示一次，不强制完成                                      |

设计边界：

* 技术动作只给奖励，不作为主线必需条件。
* Boss 可以被技能正常击杀，大圆只加速击杀。
* 技术动作冷却要短于玩家失败后的挫败感，小三角 6 秒、小圈 10 秒、大圆 18 秒足够。

## 10. 开局保护与怪物生成

### 10.1 关卡开局保护

| 规则       |                           数值 |
| -------- | ---------------------------: |
| 正式关开始不刷怪 |                        4.0 秒 |
| 正式关开始无敌  |            6.0 秒，只防敌人伤害，不防拾取 |
| 第一只怪出现时间 |                        5.5 秒 |
| 第一只怪出生距离 |                 距蛇首 ≥ 420 px |
| 第一波怪数量   |            第一关 2，第二关 3，第三关 4 |
| 第一波怪速度倍率 |                         0.75 |
| 记忆引导带    | 开局 0–8 秒，在移动方向前方生成 6–8 个破碎记忆 |
| 技能卡恢复保护  |                        0.8 秒 |

### 10.2 生成位置规则

所有敌人必须从屏幕外或安全距离生成：

```text
spawnMargin = 80–140 px outside camera
minDistanceToHead = max(360, 10 * bodyNodeSpacing)
minDistanceToAnyBody = 140 px
estimatedTimeToContact >= 2.8s
notInsideBossWarningArea
notInsideSkillCoreSafeArea
```

若生成点不合格：

```text
尝试 8 次随机边缘点
仍失败则延迟 0.5 秒
连续失败 4 次则降低该波数量 25%
```

### 10.3 刷怪强度公式

全局时间 `tMin` 为正式流程从第一关开始的分钟数，章节 `chapter` 为 1–3。

```text
hpScale = 1 + 0.18 * (chapter - 1) + 0.08 * tMin
speedScale = min(1.25, 1 + 0.06 * (chapter - 1) + 0.025 * tMin)

spawnInterval = clamp(
  2.3 - 0.18 * chapter - 0.11 * tMin,
  0.55,
  2.3
)

aliveCap = 8 + 6 * chapter + floor(tMin * 3)
```

示例：

|   时间 | 章节 | HP 倍率 | 速度倍率 | 同屏敌人上限 |
| ---: | -: | ----: | ---: | -----: |
| 30 秒 |  1 |  1.04 | 1.01 |     15 |
| 3 分钟 |  2 |  1.42 | 1.20 |     29 |
| 5 分钟 |  3 |  1.76 | 1.25 |     41 |
| 8 分钟 |  3 |  2.00 | 1.25 |     50 |

移动端 Demo 建议额外设置对象安全上限：

```text
普通敌人 active <= 55
敌方弹幕 active <= 80
玩家弹幕 active <= 90
地面拾取 active <= 120
超过上限时，低价值拾取物合并为压缩记忆
```

## 12. 随机系统与再玩一局动力

V13 采用“稀有度 + 词缀 + 保底 + 小事件”的轻量随机结构。暗黑类装备系统常用稀有度和词缀表达差异，例如 Diablo II: Resurrected 中稀有装备可拥有多条随机魔法属性；幸存者类游戏的武器进化也常以“基础武器 + 条件/配件 + 升阶结果”制造中期目标。本方案只抽取“稀有度、词缀、保底、进化节点”的思想，不引入复杂装备栏。([Wowhead][3])

### 12.1 技能卡稀有度

| 稀有度 |  权重 | 效果                     | 示例            |
| --- | --: | ---------------------- | ------------- |
| 普通  | 62% | 标准升级                   | 毒牙 Lv2        |
| 魔法  | 26% | 标准升级 + 1 条小词缀          | 毒牙 Lv2，冷却 -6% |
| 稀有  | 10% | 标准升级 + 2 条词缀，或提高数值 25% | 鳞雨 Lv3，弹跳 +1  |
| 传说  |  2% | 改变技能行为                 | 毒牙变成扇形三叉毒牙    |

限制：

```text
第 1 次技能选择：传说权重 = 0
第 2–3 次技能选择：传说权重 = 0.5%
第 4 次后：传说权重恢复
Boss 奖励：至少出现 1 张稀有或更高
```

### 12.2 保底机制

| 情况                    | 保底                    |
| --------------------- | --------------------- |
| 连续 3 次技能选择没有稀有以上      | 下一次至少 1 张稀有           |
| 到第 3 次技能选择没有防御/经济卡    | 下一次至少 1 张蜕皮、霜脊或吞忆     |
| 到第 5 次技能选择没有 Boss 输出卡 | 下一次至少 1 张毒牙、尾刺或断魂印    |
| 到第 7 次没有传说            | 第三关 Boss 奖励必出 1 个传说选项 |
| 玩家身体低于 10             | 选卡池提高防御、经济、低消耗卡权重     |

### 12.3 词缀池

| 词缀 | 稀有度 | 效果                         |
| -- | --- | -------------------------- |
| 锐化 | 普通  | 技能伤害 +12%                  |
| 急刻 | 普通  | 技能冷却 -8%                   |
| 远忆 | 普通  | 技能射程 +15%                  |
| 回声 | 魔法  | 技能有 18% 概率重复一次，重复伤害 40%    |
| 血偿 | 魔法  | 技能造成击杀时 10% 概率掉落破碎记忆       |
| 裂解 | 魔法  | 对有裂痕标记的敌人 +25% 伤害          |
| 王庭 | 稀有  | 对 Boss +18% 伤害             |
| 回身 | 稀有  | 技术动作成功后该技能立刻减少 35% 冷却      |
| 蛇蜕 | 稀有  | 学习该卡时返还 1 身体，若身体低于 10 返还 2 |
| 古誓 | 传说  | 改变技能形态，数值单独配置              |

### 12.4 随机事件

每关最多 1 个事件，第三关最多 2 个。事件不会出现在 Boss 大招期间。

| 事件   | 出现条件       | 选择           | 奖励                               | 风险               |
| ---- | ---------- | ------------ | -------------------------------- | ---------------- |

| 奖励类型  | 效果                        |

| 王血词缀  | 给当前等级最高技能添加 Boss 专属词缀     |
| 过载铭文  | `O +2`，下一张传说权重 +8%        |
| 上限突破  | 当前章节软上限 +4                |

Boss 奖励不能给纯数值小奖励。每个选项都要改变下一关策略。

### 13.2 技能消耗身体的表达

选卡界面中：

* 卡牌右上角显示 `消耗 4 节身体`。
* 蛇身尾端实时预览将被献祭的 4 节，变成半透明红色。
* 玩家点选后，尾端节点化为技能符文飞向卡牌图标。
* 消耗后身体真实变短，不能只更新 UI。

身体不足时：

```text
卡牌显示：
  当前蛇身 9
  安全线 7
  需消耗 5
  欠刻 3
```

选择后：

* 只消耗到安全线。
* 多余成本转为过载记忆。
* 蛇身上出现紫色不稳定记忆节点，表示债务。

## 15. 自动模拟器设计

### 15.1 模拟器目标

用简单 Monte Carlo 跑 1000 局，验证三件事：

* 身体长度曲线是否合理。

## 17. 风险与反例

| 风险          | 失败表现           | 防线                                |
| ----------- | -------------- | --------------------------------- |
| 身体只是数字      | 玩家不关心蛇身，只看 UI  | 所有增长、献祭、断尾都改变真实节点                 |
| 长身体变成惩罚     | 玩家故意不吃记忆       | 长身体增加拾取、攻击节点、技术动作收益；不加明显减速        |
| 技能出现太晚      | 1 分钟还在单纯吃点     | 第一技能 35–45 秒保底                    |
| 技能太频繁打断     | 玩家刚移动就被弹卡      | 技能核拾取才选卡，28 秒最小间隔                 |
| 身体不足导致高级卡废掉 | 抽到好卡却不能选       | 过载记忆允许欠刻，后续记忆偿还                   |
| 升级后身体过短     | 玩家升级等于自杀       | 安全线和过载保护，不能直接扣到死亡                 |
| 身体受击太狠      | 长身体一碰就崩        | 身体先裂痕，裂痕达阈值才断尾                    |
| 裂痕不可逆       | 被打后进入死亡螺旋      | 血温记忆、小圈、蜕皮、Boss 后修复               |
| Boss 打不到    | 自动技能只锁小怪       | Boss 独立 bossGroup，所有技能合法命中        |
| Boss 阶段锁血   | Boss 剩 1 点不死   | HP <= 0 立即死亡；阶段无敌 <= 1.2 秒；溢出伤害保留 |
| 开局脸贴脸刷怪     | 5 秒内死亡         | 4 秒不刷怪，6 秒保护，生成点安全校验              |
| 教学太啰嗦       | 面试官没耐心         | 教学 75–90 秒，开始界面可直接选第一关            |
| 随机太复杂       | Demo 做不完、玩家读不懂 | 卡牌只有 3 张，事件每关 1 个，词缀短文本           |
| 稀有度失控       | 传说卡破坏所有平衡      | 传说前期禁用，保底但限制每局数量                  |
| 经济技能太弱      | 玩家永远选伤害        | 吞忆提供拾取、偿还过载、Boss 奖励 +1 选项         |
| 防御技能太强      | 玩家无脑堆护盾        | 蜕皮只抵裂痕，不抵头部断尾                     |
| 技术动作劝退      | 玩家画不准          | 检测宽容，动作只给奖励，不阻塞通关                 |
| 弹幕对象过多      | H5 掉帧          | 对象池和主动上限，低价值拾取物合并                 |
| 物理碰撞混乱      | 蛇身被挤飞或卡住       | 蛇身用采样点 overlap，不做刚体链              |
| 关卡衔接断       | 打完 Boss 不知道去哪  | Boss 死亡后 3 秒奖励，随后自动进入下一关并展示章节名    |

创建 `src/data/V13Balance.ts` 或 `src/data/v13_balance.json`：

```ts
export const V13 = {
  body: {
    initialLength: 12,
    deathThreshold: 4,
    reserveByChapter: [6, 6, 7, 8],
    nodeSpacing: 18,
    headRadius: 16,
    bodyRadius: 10,
    hardCap: 64,
    softCapByChapter: [22, 30, 42, 56],
    headInvincibleMs: 1200,
    bodySameSourceCooldownMs: 450,
    cardResumeGraceMs: 800
  },

    baseCostA: 4,
    linear: 0.45,
    quadratic: 0.012,
```
