# V8 Open Asset Sources

These assets were added for the V8 audio/visual overhaul prototype.

- `vfx/fire/fire_circles_*.png`, `vfx/fire/fire_circles.gif`: Fire circle animation assets downloaded from OpenGameArt.
- `vfx/lightning/*.png`: Lightning bolt assets downloaded from OpenGameArt.

They are used as additive-blended VFX references and runtime overlays, not as standalone art direction. Verify the original OpenGameArt page license before non-prototype commercial use.
