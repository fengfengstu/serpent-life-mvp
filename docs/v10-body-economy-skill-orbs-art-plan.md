# 《此生为蛇》V10 设计计划书 v0.1

日期：2026-06-21  
状态：待评审，不进入实现  
目标版本：`v10-body-economy-art-pass`

## 1. 版本目标

V10 不再继续沿用 V9 的“欧洲羊皮纸战棋”方向。新的目标是以用户提供的参考图为美术基准，重做核心循环、技能系统、随机掉落、关卡与 Boss，并建立资产确认闸门。

本版本的核心判断：

> 这不是“蛇版幸存者”，而是“以身体作为生命、经验和货币的神话蛇 Roguelike”。

玩家通过吃记忆让身体变长；身体越长，生命越厚、可消费资源越多、可完成更大的蛇形技术操作。技能不是免费升级，而是通过地图掉落的技能珠触发选择，再消耗身体长度购买或升级。玩家可以放弃当前选择，积攒身体，等待下一次更值得的技能机会。

## 2. 参考项目结论

本计划吸收以下项目的方法，而不是直接照搬代码：

- `acatovic/gothicvania-codex-demo`：采用 `DESIGN-DOCUMENT + PROGRESS + ASSETS + TESTING` 的开发约束。V10 必须先有计划书、资产标准和测试标准，再实现。
- `abagames/claude-one-button-game-creation`：借鉴“玩法不变量”和“坏策略对比”。V10 需要验证只逃跑、只吃经验、无脑升级等策略不能压过认真操作。
- `fagemx/gstack-game`：借鉴 `game-review`、`balance-review`、`feel-pass`、`asset-review`、`game-qa` 的流程。V10 应按“设计评审 -> 资产评审 -> 实现 -> 手感评审 -> QA”的顺序推进。
- `petergyang/space-shooter-game`：借鉴 `SPEC.md` 的关卡、Boss、道具、移动端控制、测试写法。
- `HermeticOrmus/claude-code-game-development`：作为系统参考库，不直接安装到项目。

建议后续把 `gstack-game` 或其思想适配成项目内流程；不建议在 V10 期间盲目安装所有外部技能。

## 3. 核心乐趣

### 3.1 核心循环

```
移动穿行 -> 吃记忆 -> 身体变长 -> 拾取技能珠 -> 决定消费身体或放弃 -> 技能改变战斗效率 -> 用身体完成技术操作 -> 击败精英/Boss -> 进入更高压力关卡
```

### 3.2 核心取舍

V10 的主要决策不是“变强还是变灵活”，而是：

- 我现在是否要花掉身体学习技能？
- 我是否要先保留身体，增加生命和技术操作空间？
- 我是否有足够身体去承受 Boss 或精英怪的碰撞风险？
- 我当前 build 更适合打精英、清场、保命、吸经验，还是完成蛇形操作？

身体是四种东西的统一：

1. 生命：头部受击会掉身体。
2. 经验：吃记忆会长身体。
3. 货币：购买/升级技能会消耗身体。
4. 技术空间：更长身体更容易完成大形状和大范围闭合。

## 4. 身体经济

### 4.1 基础规则

- 初始身体：`8` 节。
- 最低保底身体：`5` 节。玩家不能消费到低于 5 节。
- 头部受击：默认掉 `1` 节身体。
- 身体归零/低于 1：死亡。
- 记忆经验：吃到普通记忆后增加身体增长进度，满格后长 1 节。
- 金色记忆：直接长 1 节，低概率出现。

### 4.2 身体增长曲线

身体不能几秒内爆到上限，也不能太慢。建议改为“身体增长进度”：

| 当前身体 | 长 1 节所需记忆点 | 设计意图 |
| --- | ---: | --- |
| 5-10 | 4 | 教学和开局快速建立成长感 |
| 11-18 | 6 | 第一关和第二关主节奏 |
| 19-26 | 8 | 中后期需要更主动击杀/吸取 |
| 27-36 | 11 | 大招身体储备，不应轻易达到 |
| 37+ | 15 | 允许极限成长，但成本很高 |

第一版建议软上限 `40` 节。超过 40 仍可继续长，但收益递减，并且 UI 需要避免挤爆。

### 4.3 受击与防御

默认受击规则：

- 头部被普通怪碰撞：掉 1 节。
- 被精英怪命中：掉 1-2 节，取决于词缀。
- 被 Boss 普通攻击命中：掉 2 节。
- 被 Boss 机制攻击命中：掉 3 节或打断技术操作。

所有受击必须有：

- 蛇头高亮闪烁。
- 掉落身体段的视觉反馈。
- 短暂击退或停顿。
- 屏幕轻震，但不遮挡视野。

## 5. 技能珠系统

### 5.1 技能珠掉落

技能珠不是每关固定次数，而是动态掉落。

掉落来源：

| 来源 | 掉落规则 |
| --- | --- |
| 普通怪 | 低概率掉落，随击杀数和停留时间略增 |
| 精英怪 | 高概率掉落 |
| Boss 阶段破防 | 高概率掉落 |
| Boss 死亡 | 必掉技能珠 |
| 随机事件 | 可临时提高技能珠掉率 |

### 5.2 掉落概率初稿

| 条件 | 基础值 |
| --- | ---: |
| 普通怪掉技能珠 | 1.2% |
| 每 60 秒停留加成 | +0.4%，上限 +2% |
| 每 40 击杀加成 | +0.3%，上限 +1.5% |
| 精英怪掉技能珠 | 65% |
| Boss 阶段破防掉技能珠 | 45% |
| Boss 死亡掉技能珠 | 100% |

软保底：

- 如果连续 `90` 秒没有出现技能珠，则普通怪掉率临时提升到 `6%`。
- 掉出技能珠后软保底重置。
- 软保底不强行指定每关次数，只防止极端脸黑。

### 5.3 技能珠选择

吃到技能珠后：

- 游戏暂停。
- 弹出 3 张随机卡。
- 卡池为全局纯随机，不按关卡锁技能。
- 可能出现当前身体买不起的技能或高阶升级。
- 身体不够时仍显示卡片，但按钮显示“需要 X 节”。
- 玩家可选择“放弃”。

放弃奖励：

- 放弃普通卡：身体增长进度 +2 点。
- 放弃高消耗卡：身体增长进度 +3 点。
- 放弃不会直接给技能，目的是鼓励积攒身体。

### 5.4 技能消费

| 技能等级 | 消耗身体 |
| --- | ---: |
| 新技能 Lv1 | 4 节 |
| Lv2 | 5 节 |
| Lv3 | 7 节 |
| Lv4 | 9 节 |
| Lv5 | 12 节 |

消费限制：

- 消费后不能低于 5 节身体。
- 如果消费会低于保底，卡片不可购买。
- 购买后身体实际变短，画面上要立刻减少尾部身体段。
- 减少身体后不视为受伤，不触发受击惩罚。

## 6. 技能设计

技能与技术操作独立。技能是 build 经营；技术操作是玩家手法。技能可以被技术操作触发或强化，但不以完成操作作为前置解锁。

技能最高 Lv5。每个技能必须有定位、触发方式、冷却、等级效果、图标、视觉要求和 QA 验收。

### 6.1 单点高伤：蛇牙飞刃

定位：自动瞄准、单体高伤、打精英/Boss。  
图标：清楚的骨质飞刃，不要魔法书。  
触发：自动朝最近高威胁目标发射。  
基础冷却：1.45 秒。

| 等级 | 效果 |
| --- | --- |
| Lv1 | 发射 1 枚骨刃，优先最近敌人 |
| Lv2 | 伤害 +35% |
| Lv3 | 变为 2 连射，每枚伤害为 Lv2 的 75% |
| Lv4 | 穿透 1 个敌人 |
| Lv5 | 优先精英/Boss 弱点，穿透 2 个敌人 |

QA：

- 玩家能看清骨刃从蛇头或身体前端发出。
- Lv3 后数量变化明显。
- 打 Boss 时能看见伤害反馈。

### 6.2 直线强攻：脊骨长枪

定位：方向性高伤，依赖蛇头朝向。  
图标：长枪/骨刺。  
触发：周期性沿蛇头方向释放。  
基础冷却：2.8 秒。

| 等级 | 效果 |
| --- | --- |
| Lv1 | 发射短直线骨枪 |
| Lv2 | 射程 +30% |
| Lv3 | 宽度 +25%，更容易命中 |
| Lv4 | 附带破甲，降低精英/Boss 护盾 |
| Lv5 | 命中 Boss 弱点时产生小爆裂 |

QA：

- 弹道必须是直线，不要看成一团光。
- 攻击方向必须和蛇头朝向一致。

### 6.3 范围清场：寒潮环

定位：范围大、伤害低、减速控场。  
图标：雪花/冰环。  
触发：周期性以蛇头为中心释放。  
基础冷却：4.8 秒。

| 等级 | 效果 |
| --- | --- |
| Lv1 | 小冰环，减速 20%，持续 1.2 秒 |
| Lv2 | 范围 +22% |
| Lv3 | 减速提升到 35% |
| Lv4 | 冰痕残留 1 秒 |
| Lv5 | 被冰环影响的敌人死亡时产生小冰片伤害 |

QA：

- 冰环透明度不能太低，边界要清楚。
- 减速状态要有冰蓝描边或脚下冰雾。

### 6.4 尾部清群：赤焰扫尾

定位：贴身范围攻击，保护后半身和尾部。  
图标：火苗/火尾。  
触发：尾部周期性挥出火焰弧。  
基础冷却：3.8 秒。

| 等级 | 效果 |
| --- | --- |
| Lv1 | 尾部释放 90 度火焰弧 |
| Lv2 | 弧线宽度 +25% |
| Lv3 | 冷却降低 18% |
| Lv4 | 命中后点燃 2 秒 |
| Lv5 | 技术操作闭合成功后，立刻追加一次强化扫尾 |

QA：

- 火焰必须从尾部发出，不是贴一张全屏火圈。
- Lv5 和技术操作联动必须明显。

### 6.5 链式中伤：雷链脊节

定位：中等伤害、链式跳跃、身体越长触发点越多。  
图标：闪电。  
触发：从身体节点周期性跳电。  
基础冷却：3.2 秒。

| 等级 | 效果 |
| --- | --- |
| Lv1 | 连接 2 个目标 |
| Lv2 | 连接 3 个目标 |
| Lv3 | 伤害 +30% |
| Lv4 | 从两个身体节点同时触发 |
| Lv5 | 最后一个目标产生小范围电爆 |

QA：

- 闪电链条要有起点和跳跃顺序。
- 不能变成屏幕噪声。

### 6.6 护身防御：鳞甲护体

定位：防御阈值、受击容错。  
图标：盾牌/鳞甲。  
触发：被动生效。  
注意：不设计“无敌”。所有防御必须有计数、冷却或消耗。

| 等级 | 效果 |
| --- | --- |
| Lv1 | 每 2 次普通头部碰撞才掉 1 节身体 |
| Lv2 | 每 3 次普通头部碰撞才掉 1 节身体 |
| Lv3 | 掉身体后 1 秒内下一次普通碰撞伤害减半，冷却 10 秒 |
| Lv4 | 掉身体时震退附近敌人 |
| Lv5 | 每损失 1 节身体，释放 3 枚鳞片反击弹，冷却 4 秒 |

QA：

- HUD 或蛇头旁需要显示防御计数。
- 防御不是永久无敌，Boss 机制攻击仍有威胁。

### 6.7 护卫挡弹：骨环护卫

定位：护身、挡弹、保护画圈过程。  
图标：环绕骨片。  
触发：持续环绕。

| 等级 | 效果 |
| --- | --- |
| Lv1 | 1 个骨片环绕蛇头，碰怪造成小伤害 |
| Lv2 | 2 个骨片 |
| Lv3 | 骨片可挡 1 次普通弹幕，重生冷却 6 秒 |
| Lv4 | 骨片碰怪伤害 +40% |
| Lv5 | 3 个骨片，技术操作闭合成功时全部飞出攻击 |

QA：

- 骨片数量变化必须可见。
- 不能遮挡蛇头方向。

### 6.8 经济成长：记忆磁场

定位：吸经验、提高身体经济效率。  
图标：磁铁/记忆漩涡。  
触发：被动。

| 等级 | 效果 |
| --- | --- |
| Lv1 | 吸取半径 +35% |
| Lv2 | 经验会缓慢飞向蛇头 |
| Lv3 | 近距离经验飞行速度 +60% |
| Lv4 | 击杀精英时自动牵引附近经验 |
| Lv5 | Boss 战中牵引场上经验，但半径有限，不全屏 |

QA：

- 吸取线或流光要清楚，不能只看见数字变。
- Lv5 不能让经验完全自动化到无脑。

### 6.9 机动手感：游蛇步

定位：速度、转向、危险逃离。  
图标：疾行箭头/蛇影。  
触发：被动 + 条件触发窗口。

| 等级 | 效果 |
| --- | --- |
| Lv1 | 移动速度 +8% |
| Lv2 | 转向响应 +12% |
| Lv3 | 险境加速：头部附近敌人过多时获得 0.8 秒加速，冷却 9 秒 |
| Lv4 | 险境加速后 1.2 秒内经验吸取增强 |
| Lv5 | 险境加速留下蛇影，蛇影吸引敌人 1 秒，冷却 12 秒 |

QA：

- 不设计穿怪无敌。
- 触发时要有蛇影/速度线，玩家知道为什么逃出来。

## 7. 技能随机与暗黑式掉落调整

### 7.1 全局纯随机卡池

用户确认卡池应更纯随机。V10 规则：

- 3 张卡从全局技能池随机抽取。
- 不按关卡锁技能。
- 可以抽到买不起的高级升级。
- 如果已有技能，随机池中包含“已有技能升级”和“新技能”，但不保证一定出现已有技能。
- 技能重复出现时，若未满 Lv5，则显示升级；已满 Lv5 的技能不再出现。

### 7.2 稀有突变

稀有突变不是普通技能，不走 Lv1-Lv5。它类似暗黑/火炬之光里的传奇特效，一局出现 0-2 次即可。

候选突变：

| 突变 | 效果 | 风险 |
| --- | --- | --- |
| 双生蛇影 | 生成影蛇，复制 25% 攻击 | 身体消费 +4 节 |
| 衔尾预兆 | 大圆闭合面积要求 -18% | 大圆触发后额外消耗 2 节身体 |
| 贪食王冠 | 记忆磁场效果 +50% | 技能升级消费 +2 节 |
| 焚骨蛇脊 | 赤焰扫尾留下火痕 | 火痕伤害低，偏清场 |
| 冰宫鳞片 | 受击掉身体时冻结近身敌人 | 冷却 12 秒 |
| 断尾求生 | 立即牺牲 4 节身体，清空近身敌人 | 仅危急时值得 |

突变出现规则：

- 极低概率从技能珠中出现。
- Boss 死亡技能珠概率更高。
- 显示为特殊卡框，让玩家知道它不是普通技能。

## 8. 蛇形技术操作

技术操作不需要前置技能。玩家只要做出来就触发。技能可以增强它们，但不是解锁条件。

### 8.1 判定基础

游戏需要记录蛇头移动轨迹，按最近若干秒的路径判断图形：

- 轨迹点间距：每移动 10-14 px 记录一点。
- 轨迹保留时间：最近 4-8 秒。
- 图形判定优先宽松，不追求数学完美。
- 技术操作触发后进入短冷却，避免重复触发。

### 8.2 三角印

目标：最低门槛甜头，让玩家知道“画形状有用”。  
条件：

- 路径形成 3 个明显转角。
- 闭合距离低于阈值。
- 面积达到小阈值。

效果：

- 对闭合区域附近敌人造成小范围斩击。
- 触发一次当前最高等级的单点技能。
- 冷却：8 秒。

设计重点：

- 必须容易做到。
- 不要求完美三角。
- 教学关必须引导一次。

### 8.3 小蛇环

目标：中级空间控制。  
条件：

- 路径闭合。
- 面积达到中阈值。
- 闭合过程中蛇头未受击。

效果：

- 圈内敌人受到范围伤害和短暂减速。
- 圈内经验向蛇头吸取。
- 冷却：14 秒。

### 8.4 衔尾大圆

目标：高手爆发和终局爽点。  
条件：

- 身体建议达到 24 节以上才更容易完成，但不写死为前置。
- 路径闭合。
- 面积达到大阈值。
- 头尾距离较近或蛇头回到自身轨迹附近。
- 闭合过程中蛇头未被关键攻击命中。

效果：

- 普通敌人：大范围清屏或重创。
- 精英：造成高额伤害并破除部分词缀护盾。
- Boss：不秒杀，造成固定阶段伤害或打掉一层护盾。
- 冷却：45 秒。

设计重点：

- 不能做成劝退操作。
- 判定要宽松，但面积要求要防止玩家原地小绕触发清屏。
- 失败也应有反馈，例如轨迹破碎，而不是玩家不知道发生了什么。

## 9. 随机要素

### 9.1 记忆词缀

| 记忆类型 | 效果 |
| --- | --- |
| 青色记忆 | 普通身体增长点 |
| 金色记忆 | 更多身体增长点 |
| 回响记忆 | 吃掉后牵引附近记忆 |
| 腐化记忆 | 增长更多，但短时间敌人速度提高 |
| 裂纹记忆 | 增长更多，但下一次受击掉落额外身体进度 |

### 9.2 局内事件

| 事件 | 效果 |
| --- | --- |
| 记忆雨 | 大量经验掉落，敌人密度略升 |
| 猩红潮 | 怪物密度提高，技能珠掉率提高 |
| 静默雾 | 视野压迫，敌人速度下降 |
| 蛇巢回响 | 技术操作判定变宽 |
| 古蛇符文 | 地图出现符文点，闭合圈住后触发奖励 |

### 9.3 精英词缀

| 词缀 | 效果 |
| --- | --- |
| 追猎 | 更积极追蛇头 |
| 分裂 | 死亡后分裂小怪 |
| 护盾 | 周期减伤 |
| 守珠 | 技能珠掉率提高 |
| 噬身 | 命中头部额外掉身体 |
| 破环 | 攻击会打断技术操作 |
| 召唤 | 周期召小怪 |
| 燃痕 | 移动留下危险区域 |

精英怪可拥有 1-2 个词缀。第三关可出现 2 词缀精英。教学关不出现词缀。

## 10. 关卡结构

V10 包含 1 个教学关 + 3 个正式关。游戏开始时玩家可选择：

- 教学关
- 第一关

### 10.1 教学关：蛇巢试炼

目标：

- 教玩家移动。
- 教“身体就是生命”。
- 教吃记忆长身体。
- 教技能珠选择和放弃。
- 教三角印。

敌人：

- 少量慢速敌人。
- 不出现复杂词缀。

Boss：试炼假面

- 低血量。
- 会召唤记忆。
- 教玩家触发三角印或小蛇环即可打出大伤害。

### 10.2 第一关：青绿遗迹

目标：

- 正式建立身体经济和技能珠循环。
- 让玩家尝试纯随机技能池。
- 允许所有技能出现。

敌人：

- 普通追击怪。
- 少量远程小弹幕怪。
- 少量 1 词缀精英。

Boss：记忆守卫

- 机制：召唤记忆和小怪。
- 玩家需要在吃经验和输出之间切换。
- Boss 阶段破防可能掉技能珠。

### 10.3 第二关：猩红侵蚀

目标：

- 提高怪物密度和受击压力。
- 让防御、护身、机动、清场类技能有价值。
- 开始压迫画圈过程。

敌人：

- 怪物数量 +35%。
- 普通怪血量 +25%。
- 精英出现率提高。
- 可能出现 2 词缀精英。

Boss：绯红蛇蜕

- 机制：冲撞、打断、召唤追猎小怪。
- 玩家需要找窗口完成小蛇环或大范围移动。
- 大衔尾可打掉一层 Boss 护盾，但不秒杀。

### 10.4 第三关：终局蛇殿

目标：

- 检验 build。
- 检验身体经济。
- 检验蛇形技术操作。

敌人：

- 怪物数量 +60%。
- 普通怪血量 +50%。
- 远程弹幕增加。
- 精英 1-2 词缀常态化。

Boss：衔尾蛇像

- 机制：阶段护盾、外圈封锁、符文点、弹幕压力。
- 玩家需要通过身体长度、技能 build 和技术操作破阶段。
- 大衔尾造成阶段性大伤害。

## 12. UI 与交互

### 12.1 摇杆

V10 必须修复摇杆不跟手：

- 使用成熟浮动摇杆。
- 手指按下位置就是摇杆中心。
- 拖动超出半径时，摇杆中心跟随滑动。
- 松手后隐藏。
- 坐标统一按 CSS 像素计算，不能被 high-DPI canvas 放大破坏。

QA：

- 390x844 和 320x568 两个视口下，摇杆中心必须在手指附近。
- 自动测试读取 pointerState、joyBase、joyKnob，偏差超过阈值即失败。

### 12.2 HUD

生命不再用心心。HUD 显示：

- 当前身体节数。
- 身体增长进度条。
- 当前技能图标和等级。
- 技能珠提示。
- Boss 血条/护盾。

HUD 风格：

- 深色实底，透明度不低于 88%。
- 金属骨质描边。
- 青绿色高亮玩家状态。
- 猩红色显示危险/Boss。

### 12.3 技能图标

技能图标必须一眼可懂：

- 火：火苗/火尾。
- 冰：雪花/冰环。
- 盾：盾牌/鳞甲。
- 雷：闪电。
- 飞刃：骨刃。
- 长枪：骨枪。
- 磁吸：磁铁/漩涡。
- 速度：箭头/蛇影。
- 骨环：环绕骨片。

禁止：

- 抽象魔法书。
- 低对比小图。
- 半透明到看不清。
- 纯装饰纹样。

## 15. QA 不变量

V10 必须新增或更新自动测试：

### 15.1 输入

- 摇杆按下点和底座位置差距低于阈值。
- high-DPI canvas 下触控方向不偏。
- 重开后玩家和摇杆状态清空。

### 15.2 身体经济

- 吃记忆能稳定增长身体。
- 受击会减少身体。
- 买技能会减少身体。
- 不能买到低于保底身体。
- 放弃技能卡会增加身体增长进度。

### 15.3 技能珠

- 普通怪概率掉落。
- 精英/Boss 掉落逻辑有效。
- 90 秒无技能珠后软保底生效。
- 卡池全局随机，不按关卡锁技能。
- 买不起的卡显示但不可购买。

### 15.4 技能效果

- 每个技能 Lv1-Lv5 至少有一项可观察变化。
- 单点技能对 Boss/精英有效。
- 范围技能伤害低于单点技能，但覆盖面更大。
- 防御技能不是无敌，有计数/冷却。
- 机动技能不穿怪无敌。

### 15.5 技术操作

- 三角印可在教学关稳定触发。
- 小蛇环在正常移动下可触发。
- 大衔尾需要足够面积，不被小圈误触发。
- 技术操作过程中头部受击会中断关键闭合。

### 15.6 视觉

- 技能图标 32px/64px 可读。
- HUD 不溢出。
- 半透明元素不影响识别。
- 玩家、敌人、经验、弹幕颜色明确。
- Boss 血条和阶段清楚。

### 15.7 坏策略检查

需要用模拟或脚本验证：

- 只逃跑不吃经验，无法稳定过关。
- 只吃经验不消费技能，会在第二/三关压力明显变高。
- 无脑见卡就买，会因为身体过短导致风险提高。
- 认真选择消费/放弃并使用技术操作，应明显优于坏策略。

## 16. 待用户评审问题

进入实现前需要确认：

1. 9 个技能是否保留，是否需要删减到 7-8 个。
2. 技能消费数值是否接受当前初稿。
3. 三角印/小蛇环/大衔尾三个技术操作是否足够。
4. 稀有突变是否先做 3 个，还是一次做 6 个。
5. 美术是否完全以附件风格为准，抛弃 V9 羊皮纸方向。
6. V10 是否先做机制原型，再做全量美术；还是必须先确认美术板再动代码。

## 17. 当前建议

建议顺序：

1. 先评审本文档。
2. 锁定技能池和身体经济。
3. 先出 3 套附件风格资产方向。
4. 用户确认一套后再实现。

不要在未确认美术板前直接重构代码。V10 的成败关键不是再多写几百行逻辑，而是机制、美术、UI、技能效果和 QA 是否终于在同一个设计标准下工作。
