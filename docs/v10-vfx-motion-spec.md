# 《此生为蛇》V10 技能动效规格 v0.1

日期：2026-06-21  
状态：用于 VFX 资产生产和代码实现  
原则：技能效果不使用整张大火环、大冰环或大范围贴图。所有技能由小组件、粒子、短弧、节点和程序路径组合。

## 1. 动效评审方式

静态组件板不适合评审技能效果。V10 改用三层评审：

1. 动效预演板：用 5 帧展示技能如何发生。
2. 组件拆分：列出需要的小粒子、小弧线、小弹道、小爆点。
3. 代码规则：定义触发点、持续时间、运动曲线、淡出方式和命中反馈。

## 2. 通用 VFX 规则

- 玩家技能主色：青绿、青白、象牙白，火系允许少量橙金。
- 敌方效果主色：猩红、紫红、暗红。
- 单个技能持续视觉不应长时间盖住主角蛇头。
- 所有粒子要有“出生、扩张/位移、衰减、消失”四段。
- 所有命中反馈至少包含：小爆点、敌人闪白/闪红、轻微震动或停顿。
- 任何范围技能都不能是一个完整实心圆贴图。

## 3. Flame Tail Sweep

定位：尾部扫尾攻击，中近距离范围伤害。

触发：

- 自动按冷却触发，或在蛇身快速转向时强化触发。
- 以尾巴或后 1/3 身体段为起点。

动效阶段：

1. `0-80ms`：尾部出现 4-8 个橙金火星。
2. `80-180ms`：生成 2-4 条短火焰弧线，沿尾部切线方向扫出。
3. `180-280ms`：弧线扩散，命中的敌人出现小爆点。
4. `280-450ms`：弧线断裂成余烬点。
5. `450-700ms`：余烬淡出。

组件：

- `vfx_fire_spark_01`
- `vfx_fire_short_arc_01`
- `vfx_fire_ember_01`
- `vfx_hit_burst_warm_01`

禁止：

- 不做完整火环贴图。
- 不做持续旋转大圆。
- 不让火焰遮住蛇头。

## 4. Frost Memory Trail

定位：蛇移动留下减速轨迹，体现“蛇身路径”的独特性。

触发：

- 由移动路径按距离采样生成。
- 优先在记忆身体段经过的位置生成更亮的冰晶。

动效阶段：

1. `0-120ms`：路径上出现青白小光点。
2. `120-260ms`：光点变成小冰晶、雪花碎片和细裂纹。
3. `260-600ms`：敌人进入后触发小冻结爆点和减速。
4. `600-1400ms`：冰晶弱脉冲，维持减速区域。
5. `1400-1800ms`：碎片逐个消失。

组件：

- `vfx_frost_mote_01`
- `vfx_frost_shard_01`
- `vfx_frost_crack_short_01`
- `vfx_frost_hit_burst_01`

禁止：

- 不做完整冰圈。
- 不做大面积半透明蓝色地毯。
- 不盖住拾取物和敌方弹道。

## 5. Spine Chain Lightning

定位：从身体记忆节点向敌人跳跃的连锁攻击。

触发：

- 从最近的记忆身体段或高亮身体节点发出。
- 选择最近敌人后，最多跳跃若干次。

动效阶段：

1. `0-80ms`：身体节点青绿脉冲。
2. `80-140ms`：第一段电弧连到最近敌人。
3. `140-260ms`：电弧跳向第二/第三敌人，中间产生节点闪点。
4. `260-360ms`：敌人出现白蓝爆点。
5. `360-520ms`：电弧碎成小火花回收。

组件：

- `vfx_lightning_node_01`
- `vfx_lightning_arc_short_01`
- `vfx_lightning_endpoint_flash_01`
- `vfx_lightning_spark_01`

禁止：

- 不做满屏雷暴。
- 不用过粗线条遮挡画面。
- 不让电弧颜色和敌方红色弹幕混淆。

## 6. 下一步

若这三类动效方向通过，下一步生成正式小组件资产：

1. 火系 4 个组件。
2. 冰系 4 个组件。
3. 链电 4 个组件。
4. 护盾、牙刃、磁吸、贯穿各 3-4 个组件。

每个组件单独透明 PNG，之后由代码组合成动画。
