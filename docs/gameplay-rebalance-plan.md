# 《此生为蛇》数值与可玩性重制计划

## 当前问题

当前版本能跑通，但不好玩，核心原因不是单个数值错，而是节奏链条还没有成立：

- 早期目标不够清楚：玩家不知道第一口、第一次技能、第一次危险分别在哪里。
- 技能反馈不够立即：选择技能后没有足够强的“我变强了”的瞬间。
- 敌人压力不成曲线：有敌人，但缺少从教学、贪婪、压迫到 Boss 的递进。
- 美术和数值没有互相服务：画面很华丽，但主体/威胁/奖励的优先级不稳定。

## 新节奏目标

| 时间 | 玩家体验目标 | 设计动作 |
| --- | --- | --- |
| 0-5s | 学会移动并看到奖励 | 起点前方放置技能核与记忆食物 |
| 5-25s | 第一次构筑选择 | 首个技能核固定在可达路径上 |
| 25-60s | 明白贪婪风险 | 普通敌人形成可躲可吃的压力 |
| 60-90s | 第二次选择与第一个组合可能性 | 技能掉落间隔缩短到 12s |
| 90-150s | 怪潮压迫形成局面 | 敌人数量和速度进入主循环 |
| 135s 或 54 击杀 | Boss 作为终点目标出现 | Boss 更早、更明确地压迫画面 |

## 数值原则

1. 玩家转向必须先舒服，再谈难度。
2. 前 30 秒可以受伤但不该突然死，保护机制保留。
3. 每次升级必须立刻有一次可见的战斗收益。
4. 普通敌人靠数量与轮廓形成压力，精英和 Boss 才允许复杂。
5. Boss 不追求高血量消耗，追求清楚的阶段变化和压迫感。

## 本轮修改

- 浮动摇杆改成跟随式：手指拖远时摇杆底座会滑动，降低“不跟手”感。
- 基础速度从 205 降到 188，转向速度从 4.8 提高到 7.2，长身体后的笨重感变弱。
- 食物吸附范围提高到 118，拾取更顺。
- 技能掉落从 16s 缩短到 12s，面试试玩更快进入构筑。
- Boss 从 150s/70 kill 提前到 135s/54 kill。
- 技能升级时触发一次即时技能效果，让选择马上可感知。
- 只把通过 Sprite Forge 质检的 impact FX 接入游戏，不放行 edge-touch 的 enemy/boss sheet。

## 后续验收

- 小屏 320x568 和主流手机 390x844 不溢出。
- 0-30 秒内必须至少能触发一次技能选择。
- 90 秒内合理游玩应有第二次技能选择。
- 击杀、受击、升级都必须有清楚反馈。
- 普通敌人、奖励、玩家蛇首三者在任意截图里都能一眼区分。
