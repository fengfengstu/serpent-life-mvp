# 《此生为蛇》V3 / Defold 决策

## 结论

V3 主线继续使用 Phaser，版本名为：

`v3-phaser-art-pass`

Defold 不替代 V3，作为并行技术验证，版本名为：

`v3-defold-spike`

当前最重要的问题不是 Phaser 无法承载，而是作品面不足：主角蛇资产、场景层、UI 风格、动效反馈和前 1-3 分钟节奏还没有达到面试展示强度。立刻迁移到 Defold 会把时间花在重写，而不是让作品变强。

## V3 Phaser 主线目标

V3 要解决的核心问题：

1. 主角蛇从程序椭圆升级为真实游戏资产。
2. 战斗场景从功能底板升级为暗金档案竞技场。
3. 命中、拾取、升级、死亡反馈明显增强。
4. UI 从工程面板升级为“蛇生档案”风格。
5. 继续保留可分享 HTML URL、移动端触控、自动化烟测和版本化发布。

V3 不做：

1. 不迁移引擎。
2. 不重写完整技能池。
3. 不做完整商业化 UI。
4. 不做 Spine 或复杂骨骼动画。
5. 不把 Defold Spike 当成正式主线。

## Defold Spike 目标

Defold Spike 的目标是判断它是否值得承接 V4，而不是替代 V3。

最小验证范围：

1. 一个可玩的暗青黑竞技场。
2. 蛇头移动和蛇身跟随。
3. 12-24 节蛇身。
4. 敌群追逐。
5. 记忆拾取和蛇身增长。
6. 火环与冰冻轨迹两个技能。
7. 命中、拾取、死亡粒子反馈。
8. HTML5 构建和独立 URL 发布。

成功标准：

1. 手机浏览器稳定运行。
2. 视觉反馈明显强于 Phaser V2。
3. 构建链可复现。
4. 包体和加载时间可接受。
5. 制作摩擦没有超过收益。

## 版本发布规则

V3 Phaser 发布到：

`/versions/v3-phaser-art-pass/`

Defold Spike 发布到：

`/versions/v3-defold-spike/`

旧版本不得覆盖：

- `/versions/v1-sprite-forge/`
- `/versions/v2-color-semantics/`

根目录可以指向最新稳定版，但版本目录必须保留历史构建。
