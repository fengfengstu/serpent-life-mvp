# 《此生为蛇》视觉系统 v2

## 当前判断

上一版的主要问题不是素材完全不能用，而是视觉语义没有硬隔离。玩家、敌人、奖励、弹道和技能都在发光，且共享金、绿、紫、玫红，导致手机屏幕上读图成本太高。

## 目标画面规则

以本轮生成的 target gameplay screenshot concept 为视觉北极星，但不直接把它当背景贴图。它只用于约束颜色、层级和可读性。

## 颜色语义

| 游戏对象 | 主色 | 禁止混入 | 说明 |
| --- | --- | --- | --- |
| 玩家蛇头 | 暗金 + 翡翠 | 玫红、红橙 | 唯一“生命主角” |
| 玩家蛇身 | 翡翠绿 + 少量暗金节点 | 玫红、紫红 | 连续身体，不能像拾取物串珠 |
| 玩家弹道 | 青白/电蓝 | 金色、玫红 | 必须和奖励、敌人分离 |
| 敌人 | 玫红 + 暗紫 | 翡翠、金色 | 威胁色，不共享玩家色 |
| 敌方弹道 | 红橙 + 白热核心 | 青白、金色 | 危险色，不共享玩家弹道色 |
| 奖励/记忆 | 琥珀金 | 青白、玫红 | 只代表可拾取收益 |
| 背景 | 深青黑 + 极低对比纹理 | 高饱和主体色 | 只做空间，不抢主体 |
| UI | 墨黑面板 + 暗金细线 + 奶白字 | 彩虹渐变 | 信息优先 |

## 运行时修改优先级

1. 玩家炮台子弹从金色改为青白。
2. 敌方/Boss 弹道从玫红改为红橙。
3. Lightning 保持青白，强化玩家弹道身份。
4. 奖励保留琥珀金，避免再用玩家翡翠色。
5. 敌人不再 tint 到浅粉，保留暗紫/玫红。
6. Boss 出场时增加红橙危险 ring，避免只靠大贴图压迫。
7. HUD 进度条不再使用绿-青-粉彩虹，改为暗金到危险红。

## 验收截图

任意战斗截图中，以下判断必须在 1 秒内成立：

- 哪个是玩家。
- 哪个是敌人。
- 哪些是玩家攻击。
- 哪些是敌人攻击。
- 哪些是奖励。
- UI 不遮挡主要战斗判断。
